# CodePath103

This repository tracks my work for CodePath's Advanced Technical Interview Prep
(TIP103). I use it to practice algorithm problems in Python and document my
solutions with the UMPIRE problem-solving flow.

UMPIRE is a way to slow down before jumping into code:

- Understand the prompt, constraints, and edge cases.
- Match the problem to familiar patterns or data structures.
- Plan the approach before writing the final solution.
- Implement the code clearly.
- Review it with happy path and edge case inputs, watching how key variables
  change.
- Evaluate the time and space complexity.

The goal is not just to get accepted answers. I want each solution to show the
reasoning behind it, so the repo can double as interview practice and a record of
how I approached each problem.

## Structure

Problems are organized by week and session:

```text
week1/
  session1/
    version1_problem1.py
    version1_problem2.py
    version1_problem3.py
```
